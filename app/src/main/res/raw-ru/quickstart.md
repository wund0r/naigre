# НаИгре: быстрый старт

НаИгре позволяет читать несколько файлов одновременно и быстро переключаться между ними. Приложение работает только с локальными файлами и не изменяет их. Ниже написан "быстрый старт", который покажет, как приложением пользоваться.

1. Нажми **Добавить файл** вверху и выбери PDF, который хочешь почитать.
2. Нажми **Читать** сверху — книга откроется. Страницы можно перелистывать свайпами или нажатием на левый/правый края экрана. Но перелистывание страниц — не основной способ передвижения!
3. Нажми кнопку поиска справа внизу (она всегда там) — откроется окно поиска.
4. Введи какой-нибудь заголовок книги — появятся подходящие результаты. Если вдруг в твоей PDF нет оглавнения - ниже объясню, как быстро и удобно его добавить.
5. Нажми на результат, чтобы перейти к нему. **+** откроет результат в новой вкладке (они внизу), а **◨** — в выноске, поделив экран пополам.
6. Долго жми кнопку поиска, чтобы открыть поиск по всему тексту. Результаты почти мгновенно откроются в выноске.
7. Понравилось? Собери все файлы кампании в одну папку и нажми **Добавить папку**, чтобы искать всё, везде и сразу!

Пример папки кампании:

```
рудники_фырфырфыра/
├── система.pdf
├── монстры.pdf
├── монстры.txt <- своё оглавнение, о нём ниже
├── заметки.md
├── хоумрулы.md
└── карты/
    ├── дорога.jpg
    ├── таверна.jpg
    └── логово_культистов.jpg
```

> НаИгре читает файлы напрямую — не удаляй их с устройства.

Теперь ты можешь молниеносно перемещаться по материалам кампании! О других возможностях — ниже.

# Какие файлы поддерживаются?

- **PDF:** поддерживаются ссылки, закладки и аннотации.
- **Папки с изображениями:** каждая такая папка — альбом; каждую картинку в альбому можно найти по имени файла. Один альбом считается одной книгой.
- **Markdown:** одна заметка `.md` считается одной книгой. НаИгре распознаёт markdown заголовки как закладки - их можно быстро найти. НаИгре пока не показывает изображения и ссылки markdown.

# Подсказки по интерфейсу (и не только)

- Нажми **+** в списке результатов поиска, чтобы открыть его в новой вкладке; удерживай для открытия результата в фоне: так можно открыть несколько вкладок из одного поиска. Открытые так вкладки пометятся **✓**, повторное нажатие переведёт на созданную вкладку.
- Удерживай имя вкладки или индикатор выноски для дополнительного меню.
- Заголовки в Markdown заметках можно нажимать — это будет их сворачивать. В этом быстром старте это тоже работает :)
- Можно прыгнуть на определённую страницу, нажав на номер страницы справа вверху.
- В **Меню → Интерфейс** можно включить полноэкранный режим. Так приложение будет отображаться даже поверх экрана блокировки: для чтения не нужно разблокировать планшет или телефон.
- Приложение поддерживает альбомную и портретную ориентацию: это меняет расположение выноски.
- Тему можно изменить в **Меню → Интерфейс**.
- Настройки → **Отображение** позволят читать PDF разворотами и пропускать обложку, если страницы в разворотах не совпадают.
- Можно использовать Syncthing или Resilio sync для синхронизации папки кампании между разными устройствами.

# Управление кампанией: стол и теги

По умолчанию все добавленные материалы находятся на **столе** — это значит, что ко всем им можно обращаться одновременно. Если какая-то книга сейчас не нужна на столе, снимите её флажок в **Библиотеке**.

Если хочется иметь несколько столов для разных кампаний, используй **теги**. Назначить материалу теги можно через его меню **⋮**. Созданные теги появятся сверху. Нажми тег, чтобы показать все материалы с ним, удерживай его для групповых действий и выбора всех его материалов.

Каждый материал по умолчанию получает свой цвет, чтобы было легко понять, из какой книги пришёл результат поиска. Задать книге собственный цвет можно в её меню **⋮** в библиотеке.

Книгу также можно **Забыть**. Это удалит её и все связанные с ней данные из НаИгре, но не исходный файл: приложение работает только на чтение.

# Если в PDF нет оглавления

Это можно исправить, не редактируя сам PDF. Положи рядом с ним файл `.txt`: каждая строка в нём станет закладкой, которую прочитает НаИгре.

Синтаксис: название закладки, затем два двоеточия и номер страницы.

```text
Убежище культистов::40
Уровень 2::80
Большая пещера::123
Приложение::150
```

Используй номера страниц самого PDF, начиная с 1, а не номера, напечатанные на страницах: они иногда не совпадают.

Если оглавлению нужна иерархия, используй заголовки `#`, как в Markdown:

```text
# Убежище культистов::40
## Уровень 2::80
Большая пещера::123
---
Приложение::150
```

В этом примере поиск по запросу «большая пещера» выдаст «Убежище культистов > Уровень 2 > Большая пещера». Заголовки без номеров страниц группируют записи; `---` сбрасывает иерархию. Положи .txt файл с совпадающим названием `название_книги.txt` рядом с `название_книги.pdf`: так оглавление подхватится автоматически при добавлении папки. Или добавь .txt вручную через меню книги **⋮ → Импорт оглавления TXT**.

# Файлы и неполадки

- Переместил файл? Нажми `Указать файл`
- Изменил файл? НаИгре, скорее всего, автоматически покажет его новую версию. Если этого не произошло в **⋮ книги** есть возможность пересканировать материал.
- Для полнотекстового поиска в PDF нужен текстовый слой: по книге-скану поиска не будет, сделай ей сначала OCR каким-нибудь способом
- Если у тебя много материалов на столе — при первом запуске им понадобится индексация (она отвечает за мгновенный поиск). Она не должна занять много времени. Я пробовал стол на полтора десятка PDFок, в одной из которых было больше тысячи страниц — мой шестилетний планшет всё быстро прочитал.
- При удалении приложения или очистке его данных теряются сведения о библиотеке и история.
