# NaIgre 26.09.1 — Russian UI and library improvements

The next public beta of NaIgre, a fast, local, read-only reference reader for
PDFs, Markdown notes and image albums.

## What's new

- **Russian translation.** NaIgre follows your device language; Android 13+ also
  offers English/Russian in the system's per-app language settings. Android 12
  and earlier follow device language. Documents, filenames, tags and search terms
  are unchanged; technical diagnostics remain English.
- **Compact library previews.** Equal-sized cards show the first PDF page, first
  album image or a few Markdown headings on the left, with text and controls on
  the right. Previews load in the background, preserve proportions and use bounded
  caches; they update when source changes are detected.
- **Library settings menu.** Reading view, Interface and Diagnostics are available
  from the Library's top-left menu. Changing theme keeps the Library and tag filter
  open; fullscreen works in both Library and reader.
- **Clearer tag filters.** All, On table and Untagged are grouped before custom
  tags, which have an outline icon and divider. Book colors remain reserved for
  identifying documents.
- **Custom book colors.** Choose a preset or use hue/saturation/brightness sliders
  and optional `#RRGGBB` input. A swatch and tab preview show the result before
  Apply. The saved color is shared by the library, tabs and search.
- **Layout fixes.** Better padding and sizing for translated labels, larger text,
  narrow Library headers, search mode/book selectors and the reference Edit button.

## Install or update

Download **NaIgre-26.09.1.apk**. Requires Android 8.0 or newer.

Already using the public 26.09.0 build? Install this APK over it, **without
uninstalling**. It uses the same package and signing key, with a higher Android
version code (64); no manual library migration is required. Obtainium users should
keep **Include prereleases** enabled.

NaIgre Debug and NaIgre Verification remain separate apps, not public-release
update targets. NaIgre never edits original documents, and has no analytics,
cloud sync or internet permission. Uninstalling/clearing storage removes its local
library metadata and history, so do not use that as an update procedure.

## Known limits

Still beta software. No OCR, document editing, Android “Open with”, or library
backup/export. Large maps use bounded-resolution rendering; extreme zoom may
remain soft. Markdown folds and image/note viewports are session-only. Language
and theme changes recreate the reader and may reset transient search/reference
panes; durable library metadata and saved tabs are retained.
